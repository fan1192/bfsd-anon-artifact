# To download the source code files for Dataset-5: 

1. Go to atcoder.jp and register/sign in to your account.
2. Download your cookies while staying signed in and put the cookies in thie directory
3. run just_once.sh to download the source code files
4. run the filter on all source files to filter out source codes that used helper functions
5. run datasetFormation.sh to compile them into binaries
